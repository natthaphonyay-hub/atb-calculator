# ATB Calculator

เว็บนับ dose ยาปฏิชีวนะชนิดฉีด บอกว่าผู้ป่วยได้รับยาไปแล้วกี่ dose เหลืออีกกี่ dose และ dose สุดท้ายตรงกับวันเวลาไหน พร้อม Pharmacist note ให้คัดลอกไปวางในเวชระเบียน

- เปิดใช้: https://natthaphonyay-hub.github.io/atb-calculator/
- เครื่องมือชุดเดียวกัน: Drip Calculator นับจำนวน amp ยาหยดต่อ 1 order https://natthaphonyay-hub.github.io/drip-calculator/

## ใช้งาน

1. เลือกยาจากรายการหรือพิมพ์ชื่อเอง ถ้าเป็นยาในรายการ แอปจะใส่ขนาดยาและหน่วยให้ พร้อมบอกให้ตรวจกับคำสั่งแพทย์ ขนาดยาที่พิมพ์เองจะไม่ถูกแทนที่
2. ใส่วันและเวลาที่ให้ยา dose แรก แอปไม่เดาให้ แล้วเลือกความถี่ ตั้งแต่ q 4 hr ถึง q 48 hr
3. ใส่ระยะเวลารักษา ช่องที่ 1 คือช่วงที่ต้องประเมิน (checkpoint ใส่หรือไม่ใส่ก็ได้) ช่องที่ 2 คือวันสิ้นสุด นับเป็นวันหรือเป็นจำนวน dose ก็ได้ สลับแล้วแอปแปลงตัวเลขให้
4. กรอกครบแล้วแอปจะออก Pharmacist note ตารางเวลาให้ยา และความคืบหน้า ณ วันเวลาที่ต้องการตรวจ แต่ละส่วนมีปุ่มคัดลอก
5. กรอกไม่ครบหรือกรอกผิด แอปจะบอกว่าขาดอะไรหรือต้องแก้อะไร และยังไม่ออก note จนกว่าจะแก้

## วิธีนับเวลา

- dose ที่แอปคำนวณแล้วตกเวลา 00:00 จะแสดงเป็น 23:59 ของวันก่อน ทั้งใน note ตาราง สรุป ความคืบหน้า และข้อความที่คัดลอก เพื่อไม่ให้สับสนว่าเป็นวันไหน
- เวลาเริ่มที่กรอกเองแสดงตามที่กรอก แม้เป็น 00:00
- ในวงเล็บเวลาให้ยาของ note เช่น q 8 hr [ 8, 16, 23.59 ] เวลาเที่ยงคืนที่คำนวณได้ก็แสดงเป็น 23.59 เช่นกัน
- ตารางบนมือถือแสดงเฉพาะ dose สำคัญก่อน (เริ่มต้น ถัดไป ครบช่วงที่ 1 ครบช่วงที่ 2) กด "แสดงทุก dose" เพื่อดูทั้งหมด แบ่งกลุ่มตามวัน
