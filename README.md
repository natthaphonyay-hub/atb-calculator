# ATB Calculator

เว็บนับ dose ยาปฏิชีวนะชนิดฉีด บอกว่าผู้ป่วยได้รับยาไปแล้วกี่ dose เหลืออีกกี่ dose และ dose สุดท้ายตรงกับวันเวลาไหน พร้อม Pharmacist note ให้คัดลอกไปวางในเวชระเบียน

- เปิดใช้: https://natthaphonyay-hub.github.io/atb-calculator/
- เครื่องมือชุดเดียวกัน: Drip Calculator นับจำนวน amp ยาหยดต่อ 1 order https://natthaphonyay-hub.github.io/drip-calculator/

## ใช้งาน

1. เลือกยาจากรายการหรือพิมพ์ชื่อเอง ถ้าเป็นยาในรายการ แอปจะใส่ขนาดยาและหน่วยให้
2. ใส่วันและเวลาที่ให้ยา dose แรก แล้วเลือกความถี่ ตั้งแต่ q 4 hr ถึง q 48 hr
3. ใส่ระยะเวลารักษา 2 ช่วง คือช่วงที่ต้องประเมิน (checkpoint) และวันสิ้นสุด นับเป็นวันหรือเป็นจำนวน dose ก็ได้
4. แอปจะออก Pharmacist note ตารางเวลาให้ยาทุก dose และความคืบหน้า ณ วันเวลาที่ต้องการตรวจ แต่ละส่วนมีปุ่มคัดลอก
